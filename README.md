# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows.

## Project Description

This project demonstrates a simple GitHub collaboration workflow.

## How to contribute

- Open an issue
- Create a branch
- Make your changes
- Submit a pull request

## Project Motivation

I created this project to practice Git and GitHub collaboration workflows.
It helps me understand how teams manage changes, reviews, and contributions effectively.

## CI

This project uses GitHub Actions for continuous integration.
